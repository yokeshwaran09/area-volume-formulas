# Maths Formulas

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![Language](https://img.shields.io/badge/language-100%25%20HTML-orange)

A quick-reference page of area and volume formulas built with HTML tables.

**Live Demo:** https://yokeshwaran09.github.io/maths-formulas/



## Overview

This project presents common geometry formulas in a single table with four columns: topic, diagram, formula, and variables. Each row is colour-coded for easy reading. It uses only HTML, with no CSS, JavaScript, or external libraries.

## Formulas Covered

| Topic | Formula |
|-------|---------|
| Parallelogram | Area = b × h |
| Trapezium | Area = ½(a + b) × h |
| Rhombus | Area = ½ × d₁ × d₂ |
| Semicircle | Area = ½πr² |
| Sector | Area = θ/360 × πr² |
| Annulus | Area = π(R² − r²) |
| Prism | Volume = Base Area × h |
| Pyramid | Volume = ⅓ × Base Area × h |
| Hemisphere | Volume = ⅔πr³ |
| Ellipsoid | Volume = ⁴⁄₃πabc |
| Regular Polygon | Area = ½ × perimeter × apothem |

## Getting Started

1. Clone the repository:
   bash
   git clone https://github.com/yokeshwaran09/maths-formulas.git
   
2. Open index.html in any web browser.

### Deploy with GitHub Pages

1. Go to **Settings** > **Pages**.
2. Under **Branch**, select `main` and the `/ (root)` folder.
3. Click **Save**.
